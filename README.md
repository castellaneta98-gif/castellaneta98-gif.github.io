# 🌐 Sito personale – Giuseppe Castellaneta

Questo repository contiene il mio **primo sito web personale**, realizzato come progetto di studio.  
L’obiettivo è presentarmi, raccontare il mio percorso e rendere disponibili le principali informazioni di contatto.

---

## 📄 Struttura del progetto

Il progetto segue il pattern **SASS 7-1** per un'organizzazione modulare e scalabile:

- `src/scss/abstracts/`: Variabili, mixin e placeholder globali.
- `src/scss/base/`: Stili base, tipografia e reset.
- `src/scss/components/`: Componenti riutilizzabili come bottoni e card.
- `src/scss/layout/`: Elementi strutturali come navbar, header e footer.
- `src/scss/pages/`: Stili specifici per ogni pagina (Home, CV, Contatti).

Le pagine principali sono:
- **Home (`index.html`)**: Presentazione personale con design moderno.
- **Curriculum (`cv.html`)**: Timeline professionale e competenze tecniche.
- **Contattami (`contattami.html`)**: Modulo di contatto ottimizzato per l'usabilità.

---

## 🛠️ Tecnologie utilizzate

- **HTML5** con semantica corretta.
- **CSS3 / SASS (Pattern 7-1)**: Uso di variabili, mixin e convenzione **BEM**.
- **Bootstrap 5**: Utilizzato per la griglia e componenti base di navigazione.
- **Google Fonts**: Integrazione di font custom (Poppins per titoli, Inter per corpo).
- **Responsive Design**: Mobile-first approach con Flexbox e Grid.

---

## 📱 Responsive Design

Il sito è completamente **responsive** e adattabile a diverse dimensioni di schermo.  
In particolare:

- Il layout è gestito tramite **Flexbox**
- Il menu di navigazione nell’header diventa un **menu hamburger** su dispositivi mobili

---

## 🎨 Gestione degli stili

Gli stili sono scritti in **SCSS** all’interno del file `style.scss`, che viene compilato automaticamente in CSS tramite l’estensione **Live Sass Compiler** di Visual Studio Code.
